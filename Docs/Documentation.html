Functional Documentation – Parking System

▸ Overview

The Parking Management System is a web application that automates the booking of parking spaces in public and private facilities. It solves common problems such as double-booking, time wasted searching for a spot, and human errors in manual tracking. The system targets two main groups: customers who want to book a spot quickly, and administrators who manage the facility and need real-time visibility and control over reservations.

▸ Core Features
  • Smart Auto-Booking: Uses an algorithm that searches for the first available spot (sorted by ID) and assigns it immediately, preventing double-booking and reducing wait time.
  • Admin Console: A text-based interface that displays all current reservations with driver name, phone number, license plate, assigned spot, and booking time. Allows deletion of any reservation to free up the spot.
  • Spot Management: When a reservation is deleted, the spot is automatically marked as available for new bookings.
  • Pre-configured Layout: The database comes with 40 pre-defined spots (A1–A10, B1–B10, C1–C10, D1–D10) for immediate use without complex setup.
  • Local SQLite Database: Stores all data persistently, ensuring information survives system restarts.
▸ User Benefits

For Customers:

  • Fast booking with simple steps via any device (mobile, desktop, tablet).
  • Instant confirmation of the assigned spot for peace of mind before arrival.
  • Transparency in knowing which spot is available without searching the lot.

For Administrators:

  • Reduced manual effort and elimination of errors from spreadsheets or paper tracking.
  • Real-time occupancy status to make quick decisions.
  • Easy spot release when cars leave, improving space utilization.
▸ Security & Compliance
  • Data Integrity: SQLite ensures reliable data storage, with easy backup via copying the database file.
  • Role Separation: The booking interface is completely separate from admin tools (console), so regular users cannot access delete or modify functions.
  • Personal Data Protection: Customer data (name, phone, plate) is handled securely and not shared with third parties.
  • Privacy Compliance: The system collects no sensitive data and can be run in a local offline environment, meeting the requirements of some organizations.
▸ Deployment & Accessibility

Requirements:

  • .NET 10 runtime or higher.
  • SQLite (embedded, no installation needed).
  • Modern browser with Blazor WebAssembly support.

Deployment Steps:

  • Clone the project and run dotnet run inside the ParkingApp folder.
  • Apply migrations to create the database: dotnet ef database update.
  • Access the web interface at https://localhost:5001, and the console via the AdminConsole project.

The system is self-contained and requires no external web server or separate database server, making it ideal for small and medium businesses.

Technical Documentation – Pivotal Code

▸ Data Models: ParkingSpot & Reservation

ParkingSpot.cs – Represents a physical parking spot.

  • int Id – Unique identifier (primary key).
  • string SpotNumber – Human-readable name like "A1", "B3".
  • bool IsBooked – Tracks whether the spot is currently occupied.

Reservation.cs – Holds all details of a booking.

  • int Id – Primary key.
  • int ParkingSpotId – Foreign key to the assigned spot.
  • string DriverName, string PhoneNumber, string LicensePlate – Customer info.
  • int DurationInHours – How long the spot is reserved.
  • DateTime StartTime – When the reservation begins (defaults to DateTime.Now).

The ParkingSpot navigation property links each reservation to its spot.

▸ ParkingService – The Auto-Booking Engine

ParkingService.cs contains the heart of the system: the AutoBookSpotAsync method.

How it works:

  1. Queries the ParkingSpots table for spots where IsBooked == false.
  2. Sorts them in descending order by Id (the highest ID first).
  3. Takes the first available spot (the "last" one in the list).
  4. If no spot is found, returns (false, null, "No spots available").
  5. Otherwise, marks the spot as IsBooked = true and links the reservation.
  6. Saves both changes to the database in a single transaction.

Why descending order? This ensures that spots are filled from the highest number downwards, which can be useful for parking lot layouts (e.g., fill the furthest spots first to keep the entrance clear). The strategy is easy to change if needed.

The method returns a tuple: (bool Success, ParkingSpot? AssignedSpot, string Message) so the caller knows if the booking succeeded and which spot was assigned.

▸ AppDbContext & Migrations

AppDbContext inherits from DbContext and defines two DbSet properties:

  • DbSet<ParkingSpot> ParkingSpots
  • DbSet<Reservation> Reservations

Migrations are used to create and update the SQLite database schema. The InitialCreate migration:

  • Creates both tables with proper foreign key constraints.
  • Seeds the database with 40 predefined spots (A1–A10, B1–B10, C1–C10, D1–D10) – all IsBooked = false.

The second migration (AddFloorsAndPhone) renamed CustomerName to PhoneNumber and added DriverName, demonstrating how the schema evolves.

SQLite was chosen for its simplicity – no separate server installation required.

▸ Program.cs – Dependency Injection & Pipeline

Service Registration:

  • builder.Services.AddDbContext<AppDbContext>(options => options.UseSqlite("Data Source=parking.db")) – Registers the database context with a SQLite connection string.
  • builder.Services.AddScoped<ParkingService>() – Makes ParkingService available for injection into controllers or components (scoped lifetime, one instance per HTTP request).

Blazor Setup:

  • AddRazorComponents() with both InteractiveServerComponents and InteractiveWebAssemblyComponents – enables a hybrid hosting model (server-side rendering + client-side WebAssembly).

Error Handling:

  • UseStatusCodePagesWithReExecute("/not-found") – redirects to a custom "not found" page for HTTP errors.
  • UseExceptionHandler("/Error") in production – shows a friendly error page.

Why this matters: The registration of ParkingService as a scoped service ensures each user gets a fresh instance with its own database context, preventing cross-request interference.

▸ Extra: Admin Console & Data Flow

The AdminConsole project (separate from the web app) uses the same AppDbContext and models to perform administrative tasks:

  • View all reservations – fetches and displays Reservations including the associated ParkingSpot.
  • Delete a reservation – removes the Reservation record and sets the linked spot's IsBooked back to false.

This demonstrates how the same data layer can be reused across different frontends (Web and Console).

Data flow summary:

  1. User submits a booking form → Web app creates a Reservation object.
  2. ParkingService.AutoBookSpotAsync finds a free spot and updates the database.
  3. Admin opens the console → queries the same database to view or modify records.

All changes are persisted in parking.db (SQLite file).

3D Lowpoly Model Pack Blender 5.1
▸ Overview

The Lowpoly Pack is a collection of low-poly 3D models designed for games, animations, and environmental scenes. The models feature a simple and stylish art style with vibrant colors, perfect for developers and designers who need ready-to-use, lightweight assets. The pack includes various natural elements (trees, grass, rocks, clouds) and extra objects, organized into collections within the Blender file for easy import and use.

▸ Core Features
  • Clear Organization: Collections include Trees (7 different shapes), Grass (3 types), Rocks (6 varied sizes and shapes), Clouds (3 clouds), plus a Boo collection with 6 additional objects (decorative or helper items).
  • Lightweight: All models have low polygon counts, improving performance in games and interactive applications, and reducing load times.
  • Ready to Use: Models come with basic materials and distinctive colors, so they can be used directly in scenes without additional tweaking.
  • Flexible Editing: Models are fully editable in Blender (add modifiers, change colors, add effects), allowing designers to customize them as needed.
  • Game Engine Compatibility: Models can be exported to common formats like FBX, OBJ, GLTF for use in Unity, Unreal Engine, or any other engine that supports these formats.
▸ User Benefits

For Designers and Artists:

  • Saves design time by providing ready-made models instead of building each element from scratch.
  • High flexibility for editing and animation thanks to the simple model structure.
  • Easy integration into various projects (natural environments, cities, fantasy scenes).

For Game Developers:

  • Low-poly models suitable for mobile and web games where performance matters.
  • Reusability of assets across multiple levels or projects without extra cost.
  • Compatibility with lighting and physics systems in popular engines after export.
▸ Security & Compliance
  • Open License: The pack is licensed under an open-source license allowing commercial and personal use, with modification and redistribution rights (check the included license file).
  • Malware-Free: Files are in Blender (.blend) format, safe and free from harmful code.
  • Version Compatibility: Created in Blender 5.1.2, but compatible with newer versions due to using basic features not tied to a specific release.
  • Privacy: The pack collects no user data; it is purely design assets.
▸ Deployment & Accessibility

How to Import:

  • Open the Lowpoly pack.blend file in Blender (version 2.8+).
  • You will find models organized in Collections in the Outliner panel on the right.
  • Drag the models you need into the current scene, or use "Append" to import them into another project.

Exporting for Use Outside Blender:

  • Select the desired models, then go to File > Export and choose the appropriate format (FBX for Unity, GLTF for web, OBJ for other software).
  • You can export an entire collection or individual models as needed.

Editing and Customization:

  • All models are editable in Edit Mode, and you can change colors via Materials or add modifiers like Subdivision Surface for more detail.

The pack is suitable for both beginners and professionals, providing ready-made assets to accelerate creative workflows.
